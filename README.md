# Non-Contact PLL-Based Tachometer

### Analog Electronic Tachometer Using Signal Conditioning and PLL-Related Circuitry

A hardware-based tachometer project designed to explore non-contact rotational speed measurement through analog electronic circuitry.

---

## 📌 Project Overview

The Non-Contact PLL-Based Tachometer is an Analog Electronics project developed using discrete electronic components and signal processing circuits.

The system explores the measurement of rotational speed without requiring physical contact with the rotating object.

The circuit incorporates XOR logic, a 555 timer and operational amplifier circuitry to process signals associated with rotational motion.

Unlike microcontroller-based tachometers, this project focuses on an analog hardware implementation.

## 🎯 Objectives

- Explore analog signal conditioning.

## 🔬 Working Principle

The project is based on detecting signals associated with the rotation of an object and processing them through analog electronic circuitry.

The general measurement concept involves:

1. Detecting a signal corresponding to rotational movement.
2. Processing the signal using the electronic circuit.
3. Conditioning the signal for further processing.
4. Using the resulting signal behaviour to determine rotational speed.

## 🔧 Hardware Implementation

The prototype uses analog electronic components rather than a microcontroller.

The circuit incorporates XOR logic, 555 timer circuitry and operational amplifiers.

The project provided practical experience in circuit construction, component integration and analog electronics.
